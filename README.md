# Turning Point Roasters — 랜딩 페이지

스페셜티 카페의 한 페이지짜리 소개 사이트. 카피 대신 **세 장의 도면**으로 매장을 설명합니다.

## 다이어그램 활용 방식 3가지

| # | 섹션 | 다이어그램 유형 | 무엇을 보여주나 |
|---|------|----------------|----------------|
| 01 | 원두의 여정 | **프로세스 (수평 흐름)** | 산지 → 로스팅 → 숙성 → 분쇄 → 추출. 직접 관리 공정(로스팅)을 accent로 강조 |
| 02 | 하루의 리듬 | **타임라인** | 07:00 오픈 ~ 22:00 마감. 피크/예약 마감(21:00)을 focal 처리 |
| 03 | 시그니처 메뉴 | **트리 (계층)** | 메뉴 → 에스프레소 바 / 필터 커피 / 논커피, 각 2개 대표 메뉴. 이달의 추천 라인 강조 |

모든 SVG는 인라인이며 외부 이미지 의존성이 없습니다. `diagram-design` 스킬의
디자인 시스템(orthogonal 커넥터, 4px 그리드, 1-accent 규칙, 하단 legend 스트립)을
따르되 팔레트만 커피 톤(warm-cafe)으로 리맵했습니다.

## 구성

```
index.html   본문 + 인라인 SVG 3종
style.css     warm-cafe 스킨 토큰 + 레이아웃
```
